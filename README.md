# ProjetoSOLID-Compras-SQLServer
Sistema de gerenciamento de produtos e compras desenvolvido em C# com arquitetura MVC e princípios SOLID. Utiliza SQL Server para armazenamento de dados, com operações CRUD e relacionamento N:N entre Compras e Produtos.
